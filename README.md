## Featured Projects

### 🤖 [Kaoru — Multipurpose Discord Bot](https://github.com/nikhilsp242/multipurpose-discord-bot)

### 🔐 [AES-LSB Image Steganography](https://github.com/nikhilsp242/AES-LSB-Steganography)
An educational implementation inspired by a research paper on image steganography. It encrypts text with AES-256-CBC, applies a deterministic XOR transformation, embeds ciphertext bits using sequential LSB replacement, and records image-quality metrics.

**Note:** This is an experimental implementation, not a faithful reproduction of the paper or a production security tool.

**Technologies:** Python, AES, OpenCV, NumPy

### 🧠 [Mental Health Analysis Using Reddit Data](https://github.com/nikhilsp242/Mental-Health-Prediction)

**Technologies:** Python, PyTorch, NLP, Deep Learning

### ✋ [Sign Language Recognition](https://github.com/nikhilsp242/Sign_Language_Recognition)

**Technologies:** Python, TensorFlow, OpenCV

### 🖼️ Current Research: Hash-Based Image Steganography
Developing a research prototype for embedding encrypted text into images using hash-based pixel selection. The implementation separates hash-table construction, pixel selection, encryption/decryption, and embedding/extraction. This work is ongoing, and results and limitations are still being evaluated.
